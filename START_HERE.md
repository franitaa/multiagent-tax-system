# Start here

Open this new folder in VS Code. Run `python start.py` in its terminal.
Then visit http://127.0.0.1:8501, enter your API key and upload `data/fixtures/w2_01.jpg`.
Compare the numbers, enter a reviewer and note, check visual verification and save.
