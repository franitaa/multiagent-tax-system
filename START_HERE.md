# Start here

Open this folder in VS Code. Copy `.env.example` to `.env` in the project root, add your own `OPENAI_API_KEY` or `ANTHROPIC_API_KEY`, and save. Leave unused keys blank. Never commit `.env`.
Run `python start.py` in the terminal. Then visit http://127.0.0.1:8501, select the matching provider, and upload `data/fixtures/w2_01.jpg`.
Compare the numbers, enter a reviewer and note, check visual verification and save.

This is the P3 team-integration demo. Other agents still contain the supplied stubs.
Do not overwrite your team's main branch. Review docs/P3_CHANGED_FILES.md with P1.
